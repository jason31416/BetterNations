# BetterNations 游戏玩法

该插件本质上提供了一套保护与入侵系统，让玩家能够建立和管理领地。

---

## 国家与城镇

领地由"国家"所有。  
国家是BetterNations系统的核心实体，本质上是玩家、领地、城镇等元素的集合体。

创建国家只需准备虚拟货币，  
选择合适的位置作为首都（通常你的基地即可），输入指令`/n create <国家名称>`。  
若当前位置有放置信标，则创建成功。

国家颜色在创建时随机生成，但可通过`/n color`指令修改。  
重命名国家使用`/n rename`。若要解散国家及其所有附属（包括城镇领地等），可使用`/n disband`。

城镇是国家的一部分，提供特殊功能（入侵章节将详细说明）。  
除首都外，可通过`/n town create <名称>`创建其他城镇。

使用`/n town core`移动城镇核心，`/n tp <城镇名>`进行传送。  
删除城镇需站在目标城镇内输入`/n town remove`（但最后一个城镇不可删除，因国家必须至少保留一个城镇）。

**简而言之：**
- 国家：领地、城镇和玩家的集合
- 城镇：国家领地的子集

## 领地宣称

领地以区块（16x16方块区域，从天空至基岩）为单位，游戏内按`F3+G`可显示边界。

只有加入国家后才能宣称领地，因为领地所有权属于国家而非个人。

对无主区块，站在目标区块使用`/n claim`即可宣称（根据服务器配置消耗虚拟货币）。  
解除宣称使用`/n unclaim`。  
批量操作可使用子命令如`/n claim square <尺寸>`和`/n claim auto`。

城镇宣称规则类似，但新增领地必须与现有城镇接壤。  
城镇宣称/解宣称分别使用`/n town claim`和`/n town unclaim`。

成功宣称后，屏幕中央将显示提示标题，进入已宣称区块时也会显示。

**简而言之：**
- 领地以区块为单位
- 城镇领地必须连续

## 国家类型、等级与权限

玩家增多时，管理会变得更复杂。

### 邀请玩家

加入国家需使用`/n join <国家名>`发送申请，  
随后将生成[决议案](#决议案)，需通过后才能加入。

退出国家使用`/n leave`。踢出他人使用`/n kick <玩家>`将创建决议案  
（但最高等级玩家需先降级才能被踢出）。

### 等级与权限

国家设有等级体系，具体取决于国家类型（下节详述）。  
国家创建者自动获得最高等级，新成员初始为最低等级。  
通过`/n rank <玩家> <等级>`修改等级，此操作将创建决议案。  
注意最高等级"所有者"仅限一人，设置新所有者时原所有者将被降级。

默认所有国家成员可在国家领地（未被城镇宣称的区块）建造，  
盟友国家成员同样享有此权限。  
中立/敌对玩家则无建造权限。

不同等级还影响政治权利，如投票权、建筑/军队管理权、领地操作权等。

除国家等级外，城镇另有角色系统：成员可担任居民、经理或镇长。  
镇长通常为城镇创建者，但可转让。角色管理通过右键核心打开GUI操作，仅镇长可调整。

特殊"绿卡"角色赋予外邦信任者居民同等权限（*开发中功能*）。

其他细节：
- TNT不影响城镇内方块（但可在国家领地爆炸，需用TNT大炮，因敌人无法直接放置）
- 活塞不能推动不同国家领地的方块

**简而言之：**
- 国家成员通过等级决定权限
- 城镇另有角色系统控制城镇领地访问权

### 决议案

决议案通常指需要投票通过的重要操作。  
不同政体下投票规则不同：独裁制仅独裁者可投票，民主制则全民皆可。

### 国家类型

国家可采用不同"政治体制"，决定其权力结构。

***独裁制：***  
极端政体，仅独裁者可决策。其他成员或可建造管理，但独裁者拥有绝对权力。

***君主制（默认）：***  
国王可授予将军/骑士等头衔。  
虽国王仍掌握绝对权力，但高级成员拥有基础决策权（如邀请/领地操作等）。

***共和制：***  
由"代表"群体投票决议。总统虽领导国家，但代表可投票罢免并替换总统。  
代表还享有更多管理权限。

***民主制：***  
全民皆可投票（但新成员默认无任何权限，需晋升为公民）。  
决议需半数成员赞成方可通过，效率较低。

***无政府状态：***  
另一极端，所有公民享有全部权限。  
国家内任何人可宣战、踢人、升降级等。适合完全信任的小团体。

## 战争、军队与条约

军事与科技系统初看复杂，但实际操作后便易于理解。

入侵他国前需用`/n declarewar <目标国家>`宣战。

### 配方

插件新增可通过工作台/熔炉制作的配方，  
使用`/n recipe`可查看配方书GUI。

### 军队

军队是攻占领土的核心单位，基本作战单元为"部队"，协同行动的部队群称为"军团"。

**四种状态：**
- 驻守：军团显示为国家色染色玻璃块，遇敌时实体化守卫。会自动攻击同区块敌军。
- 运输：军团跟随玩家移动，实体遇水即溃（可用船渡水）。实体受伤反映为军团损血，远离玩家则消亡。补给消耗加倍。
- 入侵：攻击敌方区块，HP归零时占领。仅限国家领地，不攻击同区块其他军团，需另派军队护航。切断敌方领地与城镇连接可占领整个区域。
- 围攻：攻击敌方城镇，需从接壤区块发起。多军团可同时围攻一城。

右键军团实体/方块打开GUI切换状态。  
Shift+点击驻守军团可合并运输中的部队。

**组建军队：**  
需先制作对应装备，放入兵营等训练设施。

**作战方式：**  
包括攻击运输实体、摧毁营地方块、"守卫战"等。  
驻守军团会自动与同区块敌军交战（显示红色粒子效果）。

战斗按"军团刻"计算（`/n nextupdate`查看），每刻各单位互相攻击，  
根据攻防值计算伤害，HP≤0的单位将被移除。

### 条约

条约是条款集合，需所有相关国家签署生效，  
任一相关国家可否决条约。

创建条约：`/n treaty create <名称>`，  
查看/编辑/签署：`/n treaty view <名称>`。

**条约条款：**
- 同盟：互相开放国家领地建造权，可通过`/n revoke <国家>`解除
- 和平：结束战争状态
- 其他条款开发中

### 军队补给

补给是部队存活必需品。新建部队补给满额，随时间消耗。  
将驻守部队置于有"粮仓"的区块可自动补充。  
手持食物右键粮仓转换为补给点，粮仓会缓慢为同区块友军补充补给。

***补给耗尽时部队将消亡！***
